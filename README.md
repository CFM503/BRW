# 中国燃气 - Oracle EBS 专属工作台 (v1.0.9)

[![Release](https://img.shields.io/github/v/release/CFM503/BRW?include_prereleases&style=flat-square)](https://github.com/CFM503/BRW/releases)

专门针对中国燃气 Oracle EBS 业务定制的极简、轻量专用浏览器。单个独立 exe 运行，无多余依赖，专为稳定高效办公与长周期挂机打造。

---

## 🌟 核心特色与更新日志 (v1.0.9)

1. **Java Forms (Java 6) 笔记本与高分屏深度兼容与修复**：
   - **JVM 启动参数校准**：移除导致 Java 1.6.0_27 HotSpot Client VM 致命崩溃的非法参数 `-XX:-UseImplicitNullChecks`，确保 `jp2launcher.exe` 进程秒级稳定拉起。
   - **双显卡/核显 Direct3D 安全隔离**：保持 `-Dsun.java2d.noddraw=true -Dsun.java2d.d3d=false -Dsun.java2d.dpiaware=false`，消除 Intel Iris Xe / NVIDIA 显卡在 Java 6 软件表面切换时的设备冲突与蓝屏/闪退。
   - **PE 头 DEP / ASLR 限制解除**：通过内置 `PatchPE` 工具自动剥离 `NX_COMPAT` 与 `DYNAMIC_BASE`（固定映像基址，`DllCharacteristics = 0x8400`），彻底杜绝 Windows 11 下 Java 6 JIT 动态代码执行违例。
   - **解锁 Java 安全授权提示框**：调整 `ScriptErrorsSuppressed = false`，让 Java 6 原生安全确认框（“是否运行此应用”）正常弹出供用户信任，避免静默拦截。
   - **受信任站点 (Zone 2) 策略加固**：自动注册中国燃气相关域名（`chinagasholdings.com`、`ebs`、`portal`）到 Zone 2，并注入 `1C00 = 0x00020000`（允许 Java 完全执行）及 `2500 = 3`（禁用保护模式）。

2. **多页签与弹窗调度引擎重构 (解决秒关与卡空白)**：
   - **彻底杜绝程序“秒关”**：拦截底层 MSHTML 的 `window.close()` / `WM_CLOSE` 级联关闭，主窗体强制免疫外部非正常关闭请求。
   - **NewWindow3 直接页签导航**：门户单点登录跳转 EBS 时，采用异步直接页签创建与目标 URL 导航，彻底解决 IE11 底层跨域 COM 弹窗传递丢失导致卡在空白页的问题。
   - **解除弹窗防抖限制**：移除 600ms 弹窗限制，确保 EBS Navigator 快速连续触发 `RF.jsp` 和 `frmservlet` 时顺利穿透。

3. **版本标识与界面自适应布局**：
   - **版本号显式展示**：在窗口标题栏与状态栏右下角明显显示当前运行版本号（如 `[版本: v1.0.9]`），方便排查与确认运行环境。
   - **高分屏笔记本设置窗口防错位**：采用 System DPI 模式及自适应流式排版，修复高分屏（125%/150%/200%）笔记本电脑与台式机显示不一致、设置面板按钮错位遮挡的问题。

4. **三重永久挂机防掉线引擎**：
   - **底层 C# 直接续订**：软件底层自动读取 EBS 会话 Cookie，直接向数据库后端发送原生 HTTP 保活包，无视页签关闭或切换，确保 `ICX_SESSIONS.LAST_CONNECT` 实时常青。
   - **画布级微脉冲**：深入 Java 内部真实渲染画布（`SunAwtCanvas`）投递底层消息，重置 Forms 客户端闲置计时器。
   - **智能会话看护（终极兜底）**：针对 EBS 系统的 4 小时硬性限制（`ICX: Limit Time`），当触发“您的登录会话不再有效”决定弹窗时，看护引擎会自动毫秒级代点【是(Y)】并自动调用保存的凭据完成续订，**无需人工守在电脑前，录入的日记账与凭证草稿 100% 完整保留，真正实现 24 小时永久挂机！**

5. **门户账号密码安全记录与自动填充**：
   - 可以在“⚙ 设置”中保存您的工号和密码，密码采用 **Windows 原生 DPAPI 高强度数据保护加密**，仅限本机当前登录账户解密，绝非明文存储。
   - 每次打开燃气门户登录页，浏览器会自动将账号密码填入输入框，无需重复手动敲键盘，一键登录！

6. **保活心跳间隔自由设置**：
   - 在“⚙ 设置”中支持自由调整 **保活心跳间隔（1 ~ 30 分钟）**，保存后即刻热更新生效，适配不同网络环境。

7. **单窗口多页签（Tabbed UI）设计**：
   - 彻底摆脱多弹窗杂乱痛点！点击门户进入 EBS 时，**自动在同一窗口内新建标签页**，桌面与任务栏只保留一个整洁的主窗口。
   - 自定义现代化 Tab 标签栏，支持独立标题、`[×]` 一键关闭、中键关闭与 `[➕ 新页签]`。
   - **智能防误关保护**：关闭正在运行 Oracle EBS 的页签时会弹出二次防误关确认，避免丢失未保存的表单数据。

8. **白屏与未响应彻底免疫**：
   - 启动时自动禁用冲突的 DirectDraw 硬件加速（改为稳定软件渲染），并自动清理后台残留的假死 Java 僵尸进程。

9. **底层静默脚本语法报错**：
   - 底层 COM 接管语法错误拦截，彻底杜绝登录时弹出的 `base64.js 语法错误` 干扰框。

10. **数据导出原生支持**：
    - EBS 中导出的 Excel / CSV / 报表支持直接调用 Windows 系统的保存对话框进行下载保存。

## 🚀 启动与使用方式

- **桌面快捷方式**：双击桌面的 **“中国燃气-EBS专用浏览器”** 快捷方式即可启动。
- **程序文件位置**：`d:\SOFT\ai\github\BRW\EBSBrowser.exe`

### 常用快捷键：
* `Ctrl + T`：新建标签页
* `Ctrl + W`：关闭当前标签页
* `F5`：刷新当前标签页
* `Alt + ←` / `Alt + →`：后退 / 前进
* `Ctrl + +` / `Ctrl + -`：放大 / 缩小页面（支持 50% ~ 250%）
* `Ctrl + 0`：恢复 100% 原始大小
* `Ctrl + L`：快速定位并全选地址栏

## ⚙️ 配置文件 (config.ini)

如需修改门户默认网址或窗口标题，可直接在软件工具栏点击 **“⚙ 设置”**，或直接编辑同目录下的 `config.ini`：
```ini
AppTitle=中国燃气 - Oracle EBS 专用工作台
HomeUrl=https://portal.chinagasholdings.com/group/frontend
DefaultZoom=100
```
